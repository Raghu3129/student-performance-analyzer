## 🎓 Student Performance Analyzer

This project analyzes and predicts student academic performance using machine learning.

### Dataset Features:
- Study time, absences, family background
- Previous grades (G1, G2)
- Social and lifestyle factors

### Model:
- Linear Regression

### Key Insights:
- G1 and G2 strongly predict final grade
- Study time improves performance
- Absences negatively impact results

### Outcome:
- Built a predictive model to estimate student final grades
